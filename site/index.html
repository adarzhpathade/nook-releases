Requirements & Setup

  • OS: Windows 11 (64-bit, 21H2 or higher). Windows 10 is not supported.
  • Runtime: Microsoft Edge WebView2 (included with Windows 11).
  • Installation: Per-user installer, no administrator rights needed.
  • Windows Defender note: Nook is new and unsigned, so Defender can remove it by mistake. The installer asks once, before installing, to allow the Nook folder through Defender (Windows shows its normal permission prompt). Choose Yes to install. If Nook disappears later, open Windows Security → Protection history and choose Restore.
  • SmartScreen note: Because this test build is not yet commercially code-signed, Windows SmartScreen will display “Windows protected your PC”. Click More info and then Run anyway.

Highlights

  • Live activities: Music with album colours, calls, timer, stopwatch, mic/camera privacy indicator, finished downloads.
  • Quick pop-ups: Smooth sliders for volume & brightness, battery percentage & charging sweep, Bluetooth device battery, Caps Lock, Num Lock.
  • Expandable cards: Today with local weather, Timer, Stopwatch, Music controls, Calls, and Downloads (Show in folder and Open) scrolled with the wheel.
  • Side pill: Secondary activity splits off connected by an organic liquid bridge.
  • Visibility modes: Smart (visible on desktop and windowed apps, hides when maximized), Fixed, and Hidden.
